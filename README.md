# School

Coordinated runs of small models working as an assembly line: multiple
copies of the same small model, each holding one bounded station, with
deterministic checkers between stations. In this estate these groups
are called **schools** (of models, as of fish) — coordinated movement,
no central controller beyond the protocol.

## What lives here

- Studies and evaluations for school runs: benchmarks, skills, and
  tools assessed before any trial runs.
- Trial records: configurations, station maps, gate results, and the
  honest failure log.
- The first trial workload: image generation for the light-show game
  (prompt stations, variation planning, and scored selection around a
  local image model), gated by the same checker discipline as the rest
  of the estate — flowguard labels, deterministic scoring, and a
  ledgered record.

## Status

Study phase (2026-10-21). First deliverable: an evaluation of
candidate benchmarks, skills, and tools for school runs, assessed the
estate way — fold in, adapt, build from scratch, or skip, with reasons.

Protocol grounding: the estate task market and shared-attention
design (auction rules R1-R11, MATE ladder) and the night-program
school-scaling simulation results. Correctness lives in the checker
net, never in a model's self-report.
